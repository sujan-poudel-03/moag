# Slug helper

## Overview

A single dependency-free helper that turns a title into a URL slug. It runs with Node.js 20 or later.

## Requirements

- [R-1] `slugify(text)`, exported from `src/slug.js`, lowercases the text and joins its space-separated words with single dashes, so `slugify("Hello  Big World")` returns `hello-big-world`.
- [R-2] `npm test` runs tests in `test/` covering R-1 and exits 0.
