# USD formatting helper

## Overview

Cost figures appear in several places in MOAG, and each place formats dollars its own way. This adds one small, pure helper that formats a dollar amount for display, so later work can use it everywhere. It changes no existing behaviour.

## Requirements

- [R-1] `src/utils/usd-format.ts` exports `formatUsd(amount: number | 'unknown'): string`. A finite non-negative number renders as `$` followed by the amount with exactly two decimals (`0` → `$0.00`, `0.5` → `$0.50`, `12.3` → `$12.30`, `7.129` → `$7.13`), and `'unknown'` renders as `unknown`.
- [R-2] `formatUsd` throws a `RangeError` for a negative number, `NaN`, `Infinity` or `-Infinity`.
- [R-3] `src/test/unit/utils/usd-format.test.ts` (mocha with `assert.strict`) covers every case in R-1 and R-2, and `npm run compile` passes.
