# Todo CLI

## Overview

A small command-line todo list for a single user. It needs Node.js 20 or later and stores everything in a local JSON file: no server, no account, nothing to configure.

## Requirements

- [R-1] `todo add "<text>"` adds a todo with the next integer id (starting at 1) and prints `Added <id>: <text>`.
- [R-2] `todo list` prints one line per todo in ascending id order, `<id> [ ] <text>` when open or `<id> [x] <text>` when done, or `No todos.` when there are none.
- [R-3] `todo complete <id>` marks that todo done and prints `Completed <id>`; an unknown id prints `No todo with id <id>` to stderr and exits 1.
- [R-4] Todos persist in `todos.json` in the current directory, or in the file named by the `TODO_FILE` environment variable; a missing file means an empty list.
- [R-5] The app is written in TypeScript, `npm run build` compiles it with `tsc`, and `npm test` runs tests covering R-1 to R-4 and exits 0.
